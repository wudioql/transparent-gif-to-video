# Alpha 视频格式选择

用户未指定格式时，先推荐 VP9 WebM（CRF 30），再等待确认。

| 格式 | 优点 | 代价 | 推荐场景 |
|---|---|---|---|
| VP9 WebM | 体积小、网页常用、可选 lossless | 播放端必须支持 WebM alpha | 默认网页交付 |
| VP8 WebM | 兼容较旧 WebM 环境 | 压缩效率通常弱于 VP9 | 明确需要 VP8 时 |
| ProRes 4444 MOV | 后期软件兼容好、10-bit alpha 管线 | 文件很大、并非逐字节无损 | 剪辑与合成 |
| PNG-in-MOV | RGB/RGBA 无损、概念直接 | 文件通常很大 | 无损交换 |
| qtrle MOV | QuickTime Animation 兼容 | 体积较大、较旧 | 遗留工作流 |
| FFV1 MKV | 开源、无损、适合归档 | 消费端兼容性弱 | 技术归档 |

## 默认建议

用户只说“转成透明视频”时，建议：

```text
VP9 WebM，CRF 30
```

理由是透明保留、体积和现代网页兼容性之间的平衡最好。推荐不等于自动执行，仍须确认输出路径、质量和覆盖行为。

## 何时选 lossless

只有在用户明确要求以下条件时才推荐无损：

- 后续还要反复剪辑/转码；
- 图标、像素画、细线或文字对量化非常敏感；
- 文件体积不是主要约束；
- 需要归档母版。

网页最终投放通常先使用 VP9 CRF 30；如果边缘或渐变不满意，再降低 CRF，或改用无损/母版格式。

## 不提供 MP4

普通 H.264 MP4 不承载本 skill 所需的 alpha。若用户要求 MP4，应先说明它会失去透明，且该需求不属于本 skill；不要擅自填黑底或白底。
