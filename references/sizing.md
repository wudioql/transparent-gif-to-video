# 质量与体积

GIF 转视频后的体积取决于画布尺寸、帧数、变化区域、颜色复杂度和编码器，不能仅凭 GIF 原文件大小预测。

## 推荐起点

| 输出 | 起点 | 调整方向 |
|---|---|---|
| VP9 WebM | `-b:v 0 -crf 30` | 质量不足时降到 26/24；数值越低体积越大 |
| VP9 lossless | `-lossless 1` | 文件较大，但避免 VP9 有损量化 |
| VP8 WebM | `-b:v 0 -crf 30` | 仅在兼容需求明确时使用 |
| ProRes 4444 | 固定 profile | 主要由尺寸、帧数决定，通常很大 |
| PNG/qtrle/FFV1 | 无损参数 | 由画面复杂度决定，可能显著大于 VP9 |

`-cpu-used` 主要影响编码速度和压缩效率，不改变是否保留 alpha。默认 VP9/VP8 使用 2；若用户更在意速度，可以在重新确认后提高。

先用默认 VP9 转换并在目标播放端查看。若出现文字、细线、渐变或边缘质量问题，再重新确认较低 CRF 或母版格式；不要未经确认自动重转。
