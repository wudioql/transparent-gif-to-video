# 不透明化：把 alpha 合成为实色

实际操作由 `scripts/transparent_gif_to_video.py convert` 完成，本文只定义原理和判断标准。

## 1. 数学

对每个像素：

```text
out = src_rgb × alpha + background_rgb × (1 - alpha)
```

- alpha=0：输出就是背景色，源透明像素的 RGB 不再影响结果。
- alpha=1：输出就是源颜色。
- 0<alpha<1：按比例混合。

脚本先用 Pillow 得到每一帧的 RGBA，再用 `Image.alpha_composite` 合成为 RGB，最后交给 H.264 或其他编码器。因此不透明视频不会把透明区的未定义 RGB 留给播放器处理。

## 2. 背景色策略

### 先问人（默认流程）

背景色的权威答案不在素材里，而在投放端。因此脚本把"无法确定"变成一份可提问的提案，而不是一次猜测：

```text
python scripts/transparent_gif_to_video.py suggest-background input.gif --preview options.png
```

- `evidence`：素材里能读到的全部线索及信任度；
- `options`：素材内证据在前、常见投放背景（黑/白）在后，绝不自动选中任何一个；
- `question`：`headline / context / ask / options / fallback`，照着问即可；
- `--preview`：中间帧在各候选背景上的合成对比图；
- `content_bbox`：若可见内容并集小于画布，会提示"这是留白，考虑裁切而不是填色"。

`--background ask` 在有终端时交互式提问；非交互环境下打印提案并失败退出。这是刻意的：宁可中断流程，也不要产出一个"颜色看起来还行"的错误成品。

### 显式背景（推荐）

```text
--background '#000000'
```

背景必须与最终承载视频的页面/画面一致。黑色可以是建议，但不是默认事实；白色页面若使用黑底会出现明显方块。

### `auto-edge`（严格单色）

```text
--background auto-edge
```

脚本会在每一帧寻找：alpha=0 且 8 邻域接触 alpha>0 的透明像素，然后收集这些透明像素自身的 RGB。只有全素材得到一个完全相同的 RGB 才会成功。它不会：

- 把画面全局主色当作背景；
- 将多种边缘色平均；
- 用模糊或近似外扩伪造单色；
- 把可见主体边缘色误认为透明区颜色。

如果检测到多色，必须显式传背景色。`auto-edge` 的“失败”是保护机制，因为多色平均会把不确定性变成确定的错误颜色。

## 2.5 背景证据表

脚本能拿到的、关于"背景到底是什么颜色"的独立证据，按信任度排列：

| 证据 | 信任度 | 说明 |
|---|---|---|
| 透明像素自身 RGB（全素材唯一） | 高，除非是 `#000000` | 唯一能直接当背景用的证据 |
| GIF 调色板透明索引颜色 | 中 | 作者写入的数据，可与上一条交叉验证 |
| GIF 逻辑屏幕背景索引颜色 | 低 | 多数编码器固定写 0，不能单独采信 |
| 可见主体贴边主色 | 不可用作背景 | 那是画面自己的边缘；只适合用于边缘外扩 |
| 页面/投放端实际背景 | 唯一权威 | 只有你知道，所以第 3 条确认项不能跳过 |

`inspect` 会把前四条列在 `transparent_edge.background_candidates` 里，并给出 `trust`。脚本报告证据、不合并证据：把中低信任的证据平均出一个"看起来合理"的颜色，只会把不确定性变成确定的错误。

## 3. 为什么不默认做颜色外扩

外扩是另一件事：它会把可见主体颜色复制到透明区边缘，用来服务“仍保留 alpha 的有损编码”或特殊合成管线。对已经合成为实色的输出，它通常没有必要：每个透明像素都已被明确填充，边缘不会再暴露未定义 RGB。

因此本 skill 默认只做背景合成，不做全局主色外扩。若确实要做最近邻颜色外扩，应作为单独的预处理功能并单独验证，不能偷偷混入“转不透明视频”。

## 4. GIF 特殊点

GIF 常见的是二值透明（0 或 255），但 Pillow 仍按 RGBA 通用处理半透明来源。GIF 的逐帧 disposal 可能使每帧不是简单的独立画布；脚本通过逐帧 `seek` + `convert('RGBA')` 得到已合成帧，不能用只取 palette 的简化实现替代。

不同帧可以有不同局部 palette。如果透明边缘色不是全片单色，`auto-edge` 会拒绝，避免生成带错误色块的视频。
